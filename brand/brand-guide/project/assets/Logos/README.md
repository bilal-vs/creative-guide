# Logos

The files are copied from verdant-soft.com. There are no vector source files for the lockups yet; the PNGs are high resolution.

- `verdant-logo-gradient.png`: full lockup (VS mark + "Verdant Soft"), slate blue → sage teal gradient, transparent background, 852×204. For light grounds.
- `verdant-logo-white.png`: full lockup, all white (#FFFFFF), transparent background, 4096×981. For dark grounds.
- `vs-mark-gradient.png`: the VS mark alone, gradient, transparent background, 607×542.
- `vs-mark-white.svg`: the VS mark alone, true vector, single ink white (#FFFFFF). For dark grounds and the faint background motif.
- `app-icon.png`: gradient mark on a white square, 180×180 (avatars).
