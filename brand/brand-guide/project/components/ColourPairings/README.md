# ColourPairings

Every text-on-ground pair that passes contrast in each theme. Use only these.

- **Light:** `ink`, `body`, `muted` and `highlight` (slate blue) on `bg` or `surface`. Text on a slate-blue fill is `on-blue` (white). Text on a sage-teal fill is `on-teal` (ink).
- **Dark:** `ink`, `body`, `muted` and `highlight` (sage teal) on `bg` or `surface`. Slate blue is for text 24px and up only.
- **Never:**
  - white on sage teal (2.5:1)
  - sage-teal text on light grounds (2.3:1)
  - small slate-blue text on dark grounds (3.2:1)
