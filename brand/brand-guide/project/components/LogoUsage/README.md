# LogoUsage

Which logo file goes on which ground, and the clear space around it.

- **Light theme:** `verdant-logo-gradient.png`. **Dark theme:** `verdant-logo-white.png`.
- **Placement:** top-left at `safe-x` / `safe-y`, height `logo-height` (44px at 1080 wide).
- **Clear space:** at least the height of the V on every side.
- **The marks** (`vs-mark-gradient.png`, `vs-mark-white.svg`) are for avatars and the background motif, not as a substitute for the lockup on posts.
- **Never:** recolour, stretch, outline, add shadows, or place the logo over a busy part of the image.
