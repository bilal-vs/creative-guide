# Taste probe L3 · light · Verdant single · "Four modules a clinic can't get wrong"

**Why a new round:** the user called the four L2 prompts "completely useless" (2026-10-08), before generating them, and in the same messages set the main rule and the design bar:
- **Main rule:** 70% Verdant Soft, 30% other, and the other 30% is carousels only. A single post is therefore always about Verdant. L2 tested a Founder Notes checklist, which is generic advice. Under the rule that can only be a carousel, so it was the wrong post to train single posts on.
- **Design bar:** "the visuals should look like a group of graphic designers on a high budget designed a single post… visually attractive with some functionality, not useless."

So L3 is a real Verdant single: **Project Spotlight, case study F30** (confirmed). Every version has the same 8 pieces of text. Each one is a different, agency-grade idea in which **the visual itself carries the information** (the four modules). Each also uses a different characterful typeface, so we learn which kind of font the user likes.

**Facts used:** F01 (Lahore software company), F30 (medications, allergies, visits and lab-orders modules of a healthcare management system for a psychiatrist and therapist clinic; Next.js, Node.js, Express, PostgreSQL). Scope words are kept: "we built them" refers to the four modules, never the whole system. The client is not named.

**Interface note (B):** the app window is an illustration of the module structure, not a screenshot of the client's product. A caption must never call it the real screen.

**How:**
- **Flow:** Images · Nano Banana 2 · 3:4 · 4 outputs · ingredient `brand/ref-pack/ref-pack-v2-light.png`, prompt pasted exactly as written.
- **Upload and rate** on the Taste Lab page: https://claude.ai/artifact/Rbi98WmtVZB12QcBn7edrT (tab "L3").

| Variant | Look | What it tests |

| A · Module cards | L1's winning Swiss poster, upgraded: a sharp display grotesk (Clash Display style) and a 2×2 grid of slightly raised module cards with pictograms; the Allergies card in the brand gradient. | Does the L1 winner, fixed for "font too basic" and "too flat", reach agency level? |

This post shows the four modules Verdant Soft built for a psychiatry and therapy clinic's healthcare management system: medications, allergies, visits and lab orders.

The tech stack line sits at the bottom left at about 90% of the height.

Each card's module name sits at its bottom left. The allergies card is the hero: it is filled with a smooth gradient from muted slate blue (#416D95) to soft sage teal (#74AFAD), with its pictogram and name in white. The cards carry no other words or numbers.

Text, each piece exactly as written between the double quotes:

- The headline: "Four modules a clinic can't get wrong", in a sharp, modern display grotesk in the style of Clash Display Semibold, with confident, slightly condensed letterforms and crisp angular cuts, near-black navy, very large with tight line spacing, left-aligned on up to three lines; the last three words stay together on one line and are filled with a smooth gradient from electric royal blue (#2457D6) to deep ocean teal (#007A9E). The four module names are set in the headline's display typeface, medium size, in near-black navy, except on the hero card where the name is white. Apart from the logo, the image contains exactly eight pieces of text, the ones quoted above, each appearing once and spelled exactly as given. Every other area is clean paper.

Logo: use the attached image as the Verdant Soft logo. Place it unchanged at the top left on the plain background, inside the margins, about a quarter of the image width, keeping its shape, letters and slate-blue to sage-teal gradient colours exactly as in the attached image.

Design finish: a premium brand-studio poster with characterful display typography, a strict Swiss grid, generous white space, precise pictograms and real, subtle depth in the cards, nothing decorative. Every letter is sharp and easy to read on a phone. Print design on matte paper with a very fine grain.

Portrait image, 3:4 aspect ratio.
